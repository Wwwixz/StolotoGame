# СтолоПлей — быстрые игровые комнаты (MVP)

Демо-прототип веб-приложения «Быстрые игровые комнаты на бонусные баллы» для VIP-аудитории «Столото». Пользователь задаёт параметры подбора игровой комнаты, система подбирает подходящую комнату, резервирует бонусные баллы, запускает короткий раунд с заполнением мест ботами и определяет победителя.

## Стек

- **React 18 + TypeScript**
- **Vite** — сборка и dev-сервер
- **React Router 6** — навигация
- **lucide-react** — иконки
- **Inter** (Google Fonts) — типографика

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

Продакшн-сборка: `npm run build`, предпросмотр: `npm run preview`.

## Роли

На главной странице (`/`) выбирается роль — выбор запоминается в `localStorage` и определяет доступный раздел меню. Сменить роль можно в любой момент ссылкой «Сменить роль» внизу сайдбара.

- **Пользователь** — список комнат, автоподбор, игровой цикл, история, баланс, профиль
- **Администратор** — конфигуратор комнат, анализ экономики, журнал раундов

## Экраны

### Пользователь

| Маршрут | Экран |
| --- | --- |
| `/lobby` | Лобби: баннер и популярные комнаты |
| `/games` | Все открытые комнаты: фильтр по цене, сортировка, занятость мест |
| `/auto-match` | Автоподбор комнаты по параметрам + прогноз выигрыша |
| `/rooms/:id` | Карточка комнаты: состав, вероятность победы, буст, боты, таймер |
| `/rooms/:id/waiting` | Ожидание игроков: таймер до старта |
| `/rooms/:id/bots` | Заполнение свободных мест ботами |
| `/rooms/:id/draw` | Розыгрыш: ход раунда, результаты, комбинации |
| `/rooms/:id/winners` | Победители и призы |
| `/history` | История игр с фильтрами |
| `/balance` | Баланс: доступно / в резерве / системный фонд |
| `/profile` | Профиль игрока: статистика, достижения, уровень |

### Администратор

| Маршрут | Экран |
| --- | --- |
| `/admin` | Конфигуратор комнат + предупреждения по конфигурации |
| `/economy` | Анализ экономики комнаты |
| `/log` | Журнал раундов для экспертов (ID раунда, seed, победитель) |

## Параметры игры (для организаторов)

Настраиваются в конфигураторе (`/admin`) и влияют на механику:

- **Количество мест** — размер комнаты; базовая вероятность победы игрока = `1 / количество мест`
- **Цена входа (баллы)** — сколько бонусных баллов резервируется при входе в комнату
- **Процент фонда** — доля входов, идущая в призовой фонд; остаток — доля системы
- **Буст** — покупается за баллы перед стартом раунда, один на раунд, увеличивает вес игрока при выборе победителя (по умолчанию +25%)
- **Анализ экономики** (`/economy`) показывает потенциальный фонд, долю системы, рекомендуемую цену буста и изменение доходности; конфигуратор выводит предупреждения о рискованных настройках

## Демо-сценарии

1. **Игровой цикл**: Лобби → «Играть» → карточка комнаты → «Войти в комнату» → ожидание (таймер) → заполнение ботами → розыгрыш → победители → «Сыграть ещё»
2. **Матчмейкинг**: `/auto-match` → задать количество мест, цену входа, призовой фонд, формат → «Найти комнату» → результаты с прогнозом выигрыша
3. **Ручной выбор**: `/games` → фильтры и сортировка → «Играть» в любой комнате
4. **Администрирование**: `/admin` → изменить параметры комнаты → «Сохранить» → проверка предупреждений → `/economy`
5. **Прозрачность**: `/log` — журнал раундов с ID, seed и победителем

## Статус

Готов UI-прототип фронтенда (все экраны пользовательского и административного пути). Следующие шаги по кейсу: backend с RNG и расчётом весов (рекомендуется Java), real-time обновления состояния комнаты (WebSocket/SSE), резервирование бонусных баллов, хранение состояния (рекомендуется PostgreSQL).
